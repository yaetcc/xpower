# XPower · 项目想法整理

> 整理时间：2026-09-28 · 状态：前端预览态（合约未部署）

---

## 一、项目定位

**XPower —— 三币闭环 DApp 发射台**（Launchpad）

核心定位不是单一挖矿游戏，而是**发射台**：任何人都能在这里一键起盘自己的"三币闭环 DApp"——
用户从 IGNIX 发币 → 粘贴合约地址指定为抽卡与挖矿代币 → 在本平台创建盲盒抽卡项目（消耗用户币）→ 组装 PC（花平台币 XPWR）→ 质押挖矿产出用户币。

一句话：**别人来玩你的币，你来发射你的闭环**。

| 角色 | 行为 |
|---|---|
| 项目创建者 | 从 IGNIX 发币 → 粘贴地址 → 配置盲盒/权重/定价 → 一键生成部署方案 |
| 玩家 | 花项目代币抽部件 → 花 XPWR 组装 PC → 质押挖矿赚项目代币 |

## 二、三币经济体系（核心）

| 环节 | 消耗/产出 | 代币 | 归属 |
|---|---|---|---|
| 盲盒抽部件（抽卡） | 消耗 | **用户指定代币**（IGNIX 发币） | 用户自定义 |
| 部件组装 PC | 组装费 | **平台指定代币 XPWR** | 平台收入 |
| 质押挖矿 | 产出 | **用户指定代币**（默认同抽卡币，可独立指定） | 用户自定义 |

- 抽卡消耗的用户代币全部进入平台收款地址
- 组装费（1 XPWR/台）全部进入平台收款地址
- 挖矿产出按质押算力份额分配，随时可领

## 三、盲盒创建器（指定 IGNIX 代币）

**流程**：用户从 IGNIX 创建代币 → 粘贴合约地址 → 指定为消耗代币 → 在本项目创建盲盒（他人开盒消耗该代币）。

**可配置项**：
- 消耗代币合约地址（必填，0x+40 位校验）＋ 代币符号（可留空自动取前缀）
- 盲盒总数（默认 10,000 盒）
- 盲盒单价（代币/盒）
- 单次开盒数上限
- 8 类部件权重（CPU/主板/GPU/内存/SSD/电源/散热/机箱，默认平均，可调稀有度）

**经济设计（已定稿）**：
- ✅ **无平台分成**：销售额 100% 直接归创建者
- ✅ **免盲盒创建费**：创建盲盒零成本
- 开盒得到的硬件部件可继续用于组装 PC（与核心玩法闭环）

**部署清单（8 步）**：粘贴代币 → 授权 approve → 部署盲盒协议 → 开盒消耗该代币（100% 归创建者）→ 免创建费 → 配置挖矿产出代币 → 组装费保持平台币 XPWR → 上线。

## 四、项目创建器（CREATE YOUR PROJECT · 三币闭环 DApp 发射台）

发射台核心工具——帮助任何人**一键起盘同款三币闭环项目**（无需开发）：

- **14 项配置**：项目名称 / 代币符号 / 代币名称 / 代币总量 / 抽卡单价 / 抽卡上限 / 组装费 / 档位数 / 质押释放 / 平台手续费 / 收款地址 / 创建费 / 分成 / 部件数量
- 右侧实时 JSON 配置预览
- 一键复制配置 JSON
- 生成 7 步部署清单

**附加能力**：盲盒创建（指定任意 IGNIX 代币，见上）。

## 五、页面结构与玩法闭环

```
抽卡（花用户币） → 得部件 → 集齐 8 类 → 组装 PC（花 XPWR）
                                              ↓
                     领取奖励（用户币） ← 质押挖矿（产出用户币）
```

**页面板块**（已精简）：
1. STEP 1 · 盲盒抽部件（用户指定代币）
2. STEP 2 · 组装电脑（平台指定 XPWR）
3. STEP 3 · 质押挖矿（产出用户指定代币）
4. STEP 4 · 领取奖励（用户指定代币）
5. 我的资产（待机 / 质押分块，长列表内部滚动，批量操作队列）
6. 全网状态（算力 / 供应 / 网络）
7. CREATE YOUR PROJECT（创建同款项目 ＋ 盲盒创建）

**已移除板块**：交易市场、部件市场、盲盒协议（旧 TapeOut）、持币分红。

## 六、体验细节

- 用户代币符号**跨页面实时联动**（盲盒创建器填写 → STEP1/3/4 与盲盒盖同步更新，localStorage 记忆）
- 抽卡应付金额实时显示用户代币
- 批量操作队列执行器：组装/铸造排队执行、可终止后续、失败一键重试
- 批量组装不设上限（超 50 台二次确认防误触）
